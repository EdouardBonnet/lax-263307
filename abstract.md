A hereditary graph class has strongly edge-sublinear separators if its
$m$-edge graphs admit balanced separators of size $O(m^b)$ for some
$0\le b<1$. Maximum-weight independent set admits a deterministic
quasipolynomial-time approximation scheme on every such class.
Given rational vertex weights and rational $0<\varepsilon<1$, the scheme
returns an independent set of weight at least $(1-\varepsilon)$ times
the optimum in time
$\exp((\varepsilon^{-1}\log(n+2))^{O(1)})+(\ell+1)^{O(1)}$,
where $\ell$ is the binary encoding length of the weights and accuracy
and the constants depend only on the class. No separator is required
as part of the input.
